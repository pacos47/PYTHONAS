- Αφαίρεση

x += a Πρόσθεση του α στην τιμή του x ( x = x + a)

x //= a Ακέραια Διαίρεση του α με x ( x = x // a )
x %= a Υπόλοιπο διαίρεσης του α με x ( x = x % a )
x **= a Ύψωση του α στο x ( x = x ** a )
